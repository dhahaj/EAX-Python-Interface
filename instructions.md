# V40 Testing Software

## Equipment Needed

1. V40 Test Fixture
2. An assembled 104010-x PWA
3. The connector board assembly for required models

## Setup instructions for the V40 Tester

1. Head unit is connected and secured to the test fixture.
2. Place battery connector in the proper position before clamping down the board.
3. PWA is clamped down on the head unit.
4. Test base is powered and power LED is ON.
5. All USB cables from the tester are connected to the tablet.
6. Flip all slide switches to the OFF position.
7. Connect all wires on the PWA to the connector board.

## Select a program from the device menu (e.g. V40xx00, V40xx10, etc.)

## Select the model from the popup dialog window

- Press the "Prog" button to program the board.
- Press the "Test" button to start begin testing.
